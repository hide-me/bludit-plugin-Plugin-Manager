# Bludit Plugin: Plugin Manager
This is a bludit plugin which makes managing plugins easier.
- Saves the other plugins settings before deactivation
- Restores the saved settings after reactivation (so you won't loose your plugin settings after deactivation)
- Adds a "delete" button for the deactivated plugin, which deletes the plugin folder completely and its settings.
- Adds "Install Plugin" to the top of the plugins page, which makes it possible to upload a bludit plugin zip file, extract it and install it to the plugins list
